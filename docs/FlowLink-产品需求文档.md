## 1. 产品定位与目标

FlowLink 是面向 HarmonyOS NEXT 的代理连接与节点管理工具，帮助用户通过订阅获取节点、选择节点并管理连接状态。用户自备订阅或节点服务，应用不提供节点购买、账户充值或订阅销售。

产品需要解决三个问题：

1. 首次使用时，用户能够理解“添加订阅 → 获取节点 → 选择节点 → 授权并连接”的操作顺序。
2. 日常使用时，用户能够快速确认是否连接、正在使用哪个节点，以及连接失败后如何处理。
3. 管理配置时，用户能够区分订阅来源、节点及节点筛选，更新失败时仍保留可用配置。

### 1.1 产品原则

- 无须强制注册或登录，打开应用即可配置。
- 首页只突出连接／断开一个主操作。
- 连接状态同时使用文字、图标和颜色，不单独依赖颜色。
- 只有真实会话与必要校验成功后，才显示“已连接”。
- 无数据时显示“暂无数据”或“未知”，不使用设计稿中的模拟速率、额度、延迟填充正式界面。
- 对代理范围作准确描述，不承诺未验证的全设备覆盖、IPv6 覆盖、匿名性或断线阻断能力。
- 延续 ArkUI 原生交互，适配安全区域、系统返回和窗口尺寸变化。

### 1.2 核心用户场景

| 场景 | 用户目标 | 完成标志 |
| --- | --- | --- |
| 首次配置 | 导入已有订阅并开始使用 | 至少一个支持的节点可选，连接结果明确 |
| 日常连接 | 用当前节点连接或断开 | 主操作有即时反馈，状态与真实会话一致 |
| 节点不可用 | 更换节点后重试 | 原因或处理建议可见，切换结果可确认 |
| 订阅维护 | 刷新、编辑或删除订阅 | 显示处理结果，失败不破坏原有可用数据 |
| 大屏与窗口化 | 在不同尺寸下完成同一任务 | 导航入口一致，内容与操作不重叠或裁切 |
| 故障排查 | 获取可分享的诊断信息 | 能定位阶段，导出内容不含订阅凭据 |

## 2. 范围与版本划分

### 2.1 当前实现基线

当前已接入单个订阅来源、支持范围内的节点解析、节点选择、原生 VPN 连接链路，以及首页、节点、订阅、添加／编辑、模式和简化设置界面。支持中英文资源、浅深色主题和响应式布局。

此基线不代表完整产品已完成。首次引导、独立详情页、诊断工具、部分连接异常流程及多设备运行验收仍需补齐。

### 2.2 首版交付范围 R1

首版以“可配置、可连接、可恢复、状态可信”为交付边界：

- 一个订阅来源，支持添加、编辑名称／链接、手动更新、删除确认。
- 订阅格式限定为明文或 Base64 节点列表；当前协议组合为 VLESS + TCP + REALITY + Vision。
- 节点搜索、地区筛选、名称排序、选择及明确的锁定状态。
- 全局模式：代理范围内的流量使用所选节点。
- 系统 VPN 授权、连接、验证、断开、超时及失败反馈。
- 首次使用引导、订阅详情／编辑的必要信息、基础设置及组件状态规范。
- 手机完整验收；平板、折叠屏和窗口化设备完成对应验证后，才能声称支持相应设备。

### 2.3 增强范围 R2

多订阅、配置文件导入、更多协议、真实测速、延迟排序、流量统计、连接详情、规则／直连模式、自动更新、自动重连、高级设置和完整诊断工具分阶段实现。每项功能须在数据来源、系统能力与内核行为验证后开放。

### 2.4 本期不包含

账户与云同步、节点售卖、支付、广告、社交分享、未验证的系统级网络开关。当前不提供断线流量阻断，不将其作为已具备能力宣传。

四个一级目的地：首页、节点、订阅、设置。手机使用底部导航；宽屏可将相同入口改为侧栏。二级页面通过所属分支进入，并提供明确返回路径。

│  ├─ 流量统计 P10
│  └─ 连接详情 P11

## 4. 主要操作流程

### 4.1 首次使用

启动 → 首次引导 → 添加订阅 → 校验并获取节点 → 节点列表 → 选择节点 → 首页 → 点击连接 → 必要时系统授权 → 建立连接并验证 → 显示结果。

允许跳过首次引导和稍后配置。跳过后进入首页空状态，连接按钮引导完成配置。引导是否已完成需本地记录，不应每次启动重复弹出。

### 4.2 再次进入

进入首页并恢复已保存的订阅资料，异步获取或恢复可用节点，查询真实 VPN 会话状态。页面渲染不等待订阅请求完成。不能仅凭上次界面状态恢复“已连接”。

自动建立新连接不属于 R1 默认行为；恢复已有会话的显示与主动发起新连接必须区分。

### 4.3 订阅更新

点击更新 → 更新中 → 成功则显示新节点和本次更新时间；失败则显示重试入口并保留旧地址、旧节点和上次成功信息。不得把失败时间写成“最近成功更新”。

### 4.4 更换节点

首页“切换”或节点 Tab → 搜索／筛选 → 选择节点 → 首页显示新节点。活跃连接、验证、断开或配置更新期间锁定选择，并说明需要等待或先断开。

### 4.5 编辑与删除

编辑页未保存退出时询问是否放弃；取消退出保留草稿，确认放弃不修改原资料。删除订阅必须二次确认，删除仅影响本地配置，不取消服务商提供的订阅服务。

## 5. 页面功能需求

### FR-01 启动与首次引导：P01、P02

- 启动展示 FlowLink 标识，不放广告、登录或无关操作。
- 引导说明应用用途、用户自备订阅、配置步骤和连接时可能需要的系统授权。
- 提供“添加订阅”“稍后配置”及返回能力。
- 权限解释在用户实际连接时出现，不在打开应用时预先申请与当前任务无关的权限。
- 权限拒绝或授权不可用时，保留配置并提供下一步建议。

### FR-02 首页：P03

- 顶部展示品牌、连接概览及外观入口。
- 中央区域展示环形状态、文字状态和唯一主操作，点击后立即反馈，禁止重复提交。
- 当前节点卡片展示名称、协议和切换入口；没有节点或尚未选择时分别给出对应引导。
- 模式行显示实际已应用模式，进入 P09；草稿选择不能提前改变首页标签。
- 真实出口验证结果有数据时展示；验证失败不能显示连接成功。
- 速率、连接时长等仅在有真实数据来源时展示数值；尚未接入时显示暂无数据，不能用固定样例代替。
- 无订阅时连接入口导向添加订阅；已有订阅但无节点时导向更新／错误处理；有节点未选择时导向节点列表。

### FR-03 节点列表与详情：P04、P05

- 支持按名称搜索，忽略首尾空格和英文大小写；搜索、地区和来源筛选应组合生效。
- R1 提供全部、亚洲、欧洲等地区筛选；无法识别地区的节点保留在全部列表，不根据名称推断精确服务器地理位置。
- R1 支持原始顺序与名称排序；只有取得真实延迟结果后才开放延迟排序。
- 节点行展示名称、协议、来源、选中状态；延迟未知、测量中、超时必须区分。
- 无节点与无搜索结果分别展示；后者提供重置筛选，不能误导用户重新购买或导入订阅。
- 选择受限时保留列表可阅读性，并明确限制原因。
- R2 节点详情展示来源、类型、必要服务器信息、测试结果和“使用此节点”。UUID、密码及其他凭据默认不显示。
- R2 测速须定义测量方式、目标、超时和并发限制；TCP 建连延迟与经代理的端到端测试不得混为同一指标。批量测试可以停止，失败项不影响其他项结果。

### FR-04 订阅管理与详情：P06、P08

- R1 一个订阅来源，展示名称、节点数、最近成功更新时间及更新状态；替换来源通过编辑完成。
- R2 多来源时，以稳定来源标识关联节点，提供来源筛选，不能仅凭名称或列表下标关联。
- 额度、已用／剩余流量和到期时间以服务商实际返回的数据为准。缺失显示暂无数据；订阅额度不能当作本机流量统计。
- 已过期时明确提示；是否仍能连接取决于真实服务结果，不能仅因到期提示自动宣称节点可用。
- 更新期间禁用冲突操作，提供进度或加载反馈；成功、无支持节点、请求失败、保存失败分别反馈。
- 更新失败保留原有可用数据；部分条目不支持时展示载入与跳过数量。
- 同一订阅刷新后保留仍有效的选中节点；原选中节点被移除时默认选择第一个可用节点。首次加载或替换订阅后也默认选择第一个可用节点；获取失败且无历史节点时保持无选择。
- 删除前说明影响；连接活跃时要求先断开。确认框展示后须再次检查会话与更新状态。
- 自动更新周期属于 R2，需同时定义后台限制、失败退避和最后成功时间，不能仅实现一个无实际作用的开关。

### FR-05 添加／编辑订阅：P07、P08

- 字段为订阅名称与链接；名称必填、去除首尾空白，R1 上限 80 个字符。
- 链接须为有效 HTTP／HTTPS 地址，包含主机，禁止内嵌用户名／密码；上限 4096 个字符。建议用户使用 HTTPS，不自行降低系统证书校验。
- 链接默认隐藏，可主动查看；不得在日志、Toast 或分享截图示例中回显完整凭据。
- 粘贴只由用户主动点击安全组件触发；读取失败可手动输入，不在页面打开或后台持续读取剪贴板。
- 点击保存时先校验，再进入加载态；成功后返回管理页，失败保留输入与旧配置。
- 请求成功但无支持节点，按失败处理，不能覆盖已有可用配置；首次配置时给出支持格式说明。
- 保存期间防止重复提交和草稿退出造成状态混乱；完成前不得显示成功或提前返回。
- R2 文件导入须经过系统选择器，明确支持格式、大小和解析结果；不将任意内核配置直接作为可信配置执行。

### FR-06 代理模式：P09

| 模式 | 用户可见含义 | 开放条件 |
| --- | --- | --- |
| 规则模式 | 按配置规则决定代理范围内的连接方式 | 规则来源、优先级、默认行为和 DNS 行为均已验证 |
| 全局模式 | 代理范围内流量使用所选节点 | R1 支持；不等于未验证的所有应用及所有 IP 协议均被代理 |
| 直连模式 | 代理范围内流量不经代理节点 | 直连出站与系统 VPN 行为验证完成 |

- 区分正在选择的草稿与已应用模式；应用成功后再同步首页。
- 无变更时“应用设置”不可提交；应用失败保留原模式并反馈。
- 当前未接入的模式需禁用或明确标注，不能只改变标签而不改变真实连接行为。
- R1 连接期间不支持即时更改模式，需先断开；后续热切换须单独定义失败回滚策略。

### FR-07 流量统计与连接详情：P10、P11

- R2 展示本次连接时长、上传／下载速率、流量累计、开始时间、节点、模式及断开入口。
- 速率来自明确计数器的差值与实际采样时间，建议约 1 秒刷新；界面不可见时降低采样或停止绘图。
- 区分本机隧道计数、订阅服务商额度及设备总流量；页面须标明统计口径。
- 今日、本月及最近 7 天以设备本地时区划分；需覆盖重连、进程重启、计数器归零与跨日场景。
- 未连接速率显示 0 或未连接；历史统计与暂无统计数据分开处理。当前未接入计数器时显示暂无数据，不显示假零值作为测量结果。
- 趋势图提供时间与单位、空数据状态，不能仅依靠颜色区分上传／下载。

### FR-08 设置、诊断与关于：P12～P15

- R1 外观支持跟随系统、浅色、深色；中英文随系统语言匹配，是否增加应用内语言选择见待确认项。
- 展示真实内核版本与可用性，内核加载失败提供恢复建议。
- 需要保存的偏好应在重启后恢复；主题偏好持久化属于 R1 待补项。
- 自动连接、通知、超时、日志级别等只在业务能力实际接入后开放；高级设置不得暴露未经验证的系统能力。
- R2 诊断按时间和级别筛选，支持复制、导出与清空确认；包含失败阶段、错误代码及必要版本信息。
- 导出前脱敏订阅链接、查询参数、UUID、Token、密码、REALITY 配置等；不包含完整内核配置。外部探测目标或出口地址按诊断需要最小化披露。
- 关于页展示名称、版本、真实第三方许可与数据处理说明；反馈入口在确定实际渠道后开放。

### FR-09 组件规范：P16

覆盖按钮、输入框、开关、筛选项、节点行、订阅卡片、对话框、Toast、加载态、错误态和空状态。每项包含浅深色、禁用、长文本、大字体及中英文示例。规范页不占用用户的一级导航入口。

## 6. 连接状态与异常规则

| 内部状态 | 展示含义 | 允许操作 | 关键约束 |
| --- | --- | --- | --- |
| IDLE | 未连接 | 配置、选择、发起连接 | 不显示旧会话为运行中 |
| STARTING | 连接中 | 等待；R1 需补齐取消能力 | 禁止重复连接、切节点和改订阅 |
| VERIFYING | 正在验证 | 停止／断开 | 不能提前显示“已连接” |
| CONNECTED | 已连接 | 断开、查看状态 | 以真实会话及验证结果为依据 |
| STOPPING | 断开中 | 等待 | 禁止并发创建新会话 |
| ERROR | 失败 | 重试、改配置或换节点 | 展示可行动的提示，失败会话须清理 |

- 连接取消、超时或断开后，延迟到达的成功回调不得恢复旧会话；状态事件必须匹配当前会话。
- 系统拒绝授权、无网络、节点不可达、解析失败、内核不可用、隧道建立失败与出口验证失败，应尽量区分处理建议，不回显敏感参数。
- 连接失败需要停止相关内核／隧道并释放资源；断开完成后才能回到可连接状态。
- 外部验证服务失败不能被当作连接成功；验证对外部服务的依赖、超时和数据传输应在说明中列明。
- 用户从后台返回、应用进程重启或系统结束 VPN 时，应查询真实状态并收敛界面。
- 当前未验证 IPv6、自动重连或断线阻断，不以“运行正常”“所有流量受保护”等文案扩大实际能力范围。

## 7. 数据与持久化要求

| 数据对象 | 主要字段 | R1 持久化要求 |
| --- | --- | --- |
| 订阅 | 名称、链接、最近成功更新时间、更新结果 | 名称和链接保存于应用私有存储；成功时间应持久化，当前待补 |
| 节点 | 标识、名称、来源、协议及连接参数 | 当前只在内存；来源内刷新须使用配置身份匹配，不能仅用显示名称判断 |
| 当前选择 | 节点标识及有效性 | 重启恢复属于待补项，恢复前校验节点仍存在且配置一致 |
| VPN 会话 | 会话标识、阶段、出口校验结果 | 从真实会话查询恢复，不把旧 UI 快照作为连接事实 |
| 偏好 | 外观、引导完成状态；后续其他设置 | 应本地保存，缺省值明确 |
| 测量与统计 | 延迟、测量时间、计数、采样窗口 | R2 定义保存周期与清理策略，不能与服务商额度混用 |

补充要求：

- 订阅下载沿用当前 2 MiB 内容上限及 2000 条非空记录解析边界，超出时给出可理解的失败提示；后续调整须经过资源占用验证。
- 新配置只有在校验、获取、解析和保存均成功后才提交；失败后保留上次可用版本。
- R1 不持久化完整节点凭据与生成的内核配置。因此冷启动、离线且无内存节点时，须说明需要联网获取节点，不承诺离线连接。
- 订阅名称不强制唯一；未来多订阅必须使用独立来源标识。
- 最近成功时间与最后尝试结果分开表达；缺失时间不能用当前时间补成成功记录。
- 私有存储不等于已经实现额外加密，不作超出实现的保护承诺。当前应用关闭备份，后续改变需重新评估凭据处理。

## 8. 视觉、适配与可访问性

### 8.1 视觉规范

| 项目 | 要求 |
| --- | --- |
| 风格 | 深蓝黑背景、蓝灰分层卡片、蓝色主操作、青绿色成功状态 |
| 主按钮 | 当前主操作蓝色 #3268D6，搭配白字；颜色以 resources 令牌维护 |
| 水平留白 | 基准 20vp，窄屏可按可用空间调整 |
| 间距 | 4／8／12／16／24／32vp |
| 卡片／按钮圆角 | 基准 20vp／14vp |
| 字号 | 标题基准 24fp，小标题 18fp，正文 14～16fp；以最终规范与适配结果为准 |
| 触控 | 主按钮最小高度 52vp；主要触控目标至少 48vp |
| 对比度 | 普通启用文字目标至少 4.5:1；实际颜色组合均须检查 |

以上尺寸是项目设计规范，不作为鸿蒙官方强制值引用。正式应用不渲染 Figma 评审工具栏、模拟设备框、模拟系统状态栏或“演示数据”控制器。

### 8.2 多设备要求

- 覆盖 320、390、840、1024vp 等代表性可用窗口宽度；这些值是布局测试点，不与某个硬件型号强绑定。
- 当前实现以窗口宽度 840vp 为侧栏切换点，侧栏基准宽 200vp；页面分栏按扣除导航后的内容宽度计算。
- 宽屏内容限制最大宽度，首页可左右分栏，节点可多列；小窗口回到单列，不缩小字体来强行容纳。
- 窗口调整或折叠展开时保留编辑草稿、当前选择和真实会话状态，不重复发起网络请求或连接。
- 低高度和键盘弹出时，字段、校验提示及保存操作可通过滚动到达；固定导航不得覆盖内容。
- 系统返回、手势返回和页内返回遵守同一草稿／会话规则。
- 主题变化不能触发重复连接或丢失状态；深浅色资源完整对应。
- 英文、长节点名、大字体与读屏标签须单独验证；文本截断不能导致主要操作失去含义。

## 9. 技术与能力约束

- 页面路由统一采用 Navigation、NavPathStack、NavDestination；一级目的地切换避免无限累积返回栈。
- 新增界面与共享状态统一使用 V2 装饰器，不混入旧版状态装饰器方案。
- 用户可见固定文字、颜色均由 resources 提供；中文、英文键与格式参数保持一致，颜色提供浅深主题对应值。
- 界面与订阅／VPN 控制层分离；耗时的网络、解析及 Native 工作不得阻塞主线程。
- 当前链路为系统 VPN 路由 → TUN → Hev 用户态转发 → Xray 协议处理 → 上游节点；不把 TUN fd 本身等同于代理连接已经成立。
- IPv4 与指定协议组合已有真机记录；IPv6 双栈路由、DNS、转发与验证于 2026-10-21 接入代码，公网端到端仍待已知可用节点验收。更多协议、网络切换、其他 CPU 架构须单独验证，详见 [IPv6 实现与验证](ipv6-support.md)。
- VPN 进程与界面进程的状态同步不携带节点凭据；本地转发端口不对外暴露。
- Figma 中的交互成功只用于设计评审，不能替代真机的权限、隧道、出口与资源回收验证。

## 10. 质量与性能要求

| 项目 | 要求与验证方式 |
| --- | --- |
| 首屏 | 页面先渲染，订阅获取异步进行；网络故障不阻止进入配置界面 |
| 操作反馈 | 点击连接、更新和保存后立即进入明确的处理状态；重复点击不产生重复任务 |
| 搜索与列表 | 在 2000 条记录边界下检查输入、筛选、排序与滚动；不得出现明显卡顿或输入阻塞 |
| 超时 | 请求与连接必须有上限，并在结束后收敛状态；具体数值与实际实现配置一致 |
| 生命周期 | 覆盖前后台切换、系统终止、重新进入、网络不可用及会话退出 |
| 资源 | 反复连接／断开后无持续增长的线程、描述符或计时器；失败不遗留占用的隧道 |
| 日志与凭据 | 日志、错误提示、导出和进程事件不包含完整订阅链接与节点密钥 |
| 构建与检查 | 编译成功、资源引用／语言／主题检查通过；检查器未扫描任何文件不能算通过静态检查 |

首屏时长、内存、耗电和列表响应的具体数值预算需在目标设备建立基线后确认，不把未测量的数字作为既有性能承诺。

## 11. 验收清单

以下为验收用例，未勾选表示本文不宣称已经通过。

### 11.1 配置与列表

- [ ] AC-01：全新安装无登录阻断，可跳过引导进入首页，空状态能引导添加订阅。
- [ ] AC-02：名称为空、链接无效、超长输入分别显示对应错误，不发起保存或请求。
- [ ] AC-03：有效订阅载入支持节点，明确显示跳过数量；正式页面无固定示例节点。
- [ ] AC-04：存在旧节点时模拟请求失败、无支持节点和保存失败，旧地址、节点及选择不被错误覆盖。
- [ ] AC-05：搜索、地区和排序产生正确结果，无结果可重置；未知地区节点仍可在全部列表找到。
- [ ] AC-06：选择节点后首页同步；连接、验证、断开或更新期间不可并发更换配置。
- [ ] AC-07：编辑草稿返回时可取消退出或放弃，未确认前原配置不变化。
- [ ] AC-08：删除确认取消不改变数据；确认删除后本地来源和节点状态一致，服务商订阅不受影响。
- [ ] AC-09：粘贴仅在用户操作后读取，拒绝／失败可继续手工配置；链接默认隐藏。

### 11.2 连接与模式

- [ ] AC-10：首次连接按系统实际能力请求授权；拒绝后不显示已连接，不丢失配置。
- [ ] AC-11：真实节点建立隧道并完成出口验证后显示已连接，断开后状态与资源回收一致。
- [ ] AC-12：节点超时、无网络、内核加载失败、隧道失败及验证失败均有可理解反馈，且能重试。
- [ ] AC-13：连接取消后即使收到旧成功回调，也不能恢复为已连接。
- [ ] AC-14：应用重新进入及系统结束 VPN 后，界面状态能与真实会话同步。
- [ ] AC-15：模式页与实际内核一致；不支持的模式不能被当作已应用，无变更不能重复应用。
- [ ] AC-16：无测量数据时不展示假的延迟、速率、时长或订阅额度。

### 11.3 适配与交付

- [ ] AC-17：中文／英文、浅色／深色、代表性窗口尺寸、大字体、长名称及键盘弹出均可完成核心操作。
- [ ] AC-18：平板／折叠或窗口尺寸切换不丢失草稿，不重启已有连接；手机底栏与宽屏侧栏入口一致。
- [ ] AC-19：读屏能辨识连接状态、节点选择、输入错误与禁用原因；状态不只由颜色表达。
- [ ] AC-20：构建、资源与有效静态检查通过；新增资源和实际依赖的许可资料齐全。
- [ ] AC-21：保存测试设备、系统／应用版本、步骤、结果与必要截图；Figma 预览不能充当真机通过证据。

R2 的多订阅、真实测速、统计、规则模式、自动更新及日志导出须各自补充验收用例后交付，不沿用 R1 的通过结论。

## 13. 建议实施顺序

1. **补齐 R1 闭环**：引导、P08 必要信息、主题／成功时间／选择恢复策略、连接取消、错误与失败回归。
2. **完成 R1 设备验收**：手机端到端连接，平板、折叠屏、窗口变化、英文、大字体与读屏；记录具体设备范围。
3. **推进详情与数据**：P05／P10／P11，先确定真实测速与统计口径，再开放数值和图表。
4. **扩展配置能力**：多来源、文件格式、自动更新；每项单独处理失败保留与节点身份。
5. **扩展连接与工具**：规则／直连、自动重连、高级设置、脱敏诊断与完整关于页。

设计可按原来的五批方式推进，但不能以设计生成顺序代替功能依赖或发布验收。
