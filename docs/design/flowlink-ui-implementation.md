# FlowLink UI 实现

日期：2026-10-21。依据 [Figma Make 设计稿](https://www.figma.com/make/xh3PiB8zKAYfgvqgSsNVRe/) 的首页视觉基准和第二批核心页面实现原生 ArkUI 界面。

## 页面与导航

- 首页：环形连接状态、主连接按钮、当前节点、代理模式、统计占位与真实出口验证结果。
- 节点：搜索、地区筛选、名称排序、选中反馈；连接或更新期间禁止更换节点。
- 订阅管理：来源卡片、刷新、编辑、删除确认、加载与失败反馈。
- 添加／编辑订阅：名称、密码型链接输入、格式校验、系统 PasteButton 临时授权粘贴、未保存返回确认。
- 代理模式：显示规则／全局／直连的设计结构，当前只允许已实现的全局模式。
- 设置：提供四个一级目的地中的设置入口，接入真实外观切换和内核版本信息；设置页完整设计尚未生成，本轮只实现必要内容。

所有页面由 `Navigation + NavPathStack + NavDestination` 管理。一级目的地替换当前根页面，二级页面入栈，返回后回到来源页面。新增组件统一使用 V2 装饰器。

## 适配与资源

公共 PageScaffold 在可用窗口宽度达到 840vp 时切换为 200vp 侧栏；较窄窗口使用四项底部导航。内容限制最大宽度，首页和节点列表按各自内容宽度分栏。短窗口及软键盘场景可以滚动；按钮采用最小高度并允许文本增加高度。

颜色在 base / dark 资源中成对定义，文本在 base / en / zh_CN 中维护，品牌改为 FlowLink，保留已有 bundle 标识和 VPN 通道。新增矢量图标位于资源目录。

## 实际功能边界

- 接入现有真实订阅、节点选择、VPN 状态、连接／断开和出口校验，未引入设计稿的模拟节点或成功状态。
- 保持现有单订阅存储能力，增加订阅名称；不把设计稿中的多个卡片作为虚构数据展示。
- 更新失败时保留上一次有效地址、节点和选择；更新过程中禁止启动连接或更换节点。
- 额度、到期、速率、延迟暂无对应数据时明确显示未知或暂无数据。规则／直连、测速、配置文件导入尚未接入，不表示已经可用。
- 粘贴通过安全组件临时授权；没有添加常驻剪贴板权限。静态编译器仍会提示剪贴板读取权限，需区分该提示与 PasteButton 的临时授权流程。

- 真机发现并修复 BuilderParam 上下文导致的启动退出；修复后正常进入各一级页、代理模式页和编辑订阅页。

- CLI lint 返回 Files checked: 0，因此不作为有效 lint 验收。编译保留现有 VPN 异常处理提示和少量新页面的异常／权限静态提示。
- 宽屏、英语、大字体已经实现布局及资源支持，但本轮没有兼容 API 24 的平板／折叠屏实例可作运行验收，不声称这些设备全部验证完成。
