# HarmonyProxy 第一版视觉设计

设计日期：2026-10-20。

Figma Make 文件：[高保真移动端 UI 设计](https://www.figma.com/make/dzrDluHumD6RboyI5I7vBs/)。

## 范围

- 首页、节点页、订阅页各提供浅色与深色版本，共六张主设计稿。
- 提供可点击的手机原型、设计总览和组件规范。
- 默认简体中文，支持 English 切换，检查长文案与中英文混排。
- 子页顶部返回，沿用现有 Navigation / NavDestination 的页面结构。

## 视觉方向

专业、安静、可信的移动网络工具。浅色以雾白与白色表面为主，深色以炭黑与分层表面为主；使用克制的青绿色作为强调色。重视文字层级、留白、细线图标和一致的圆角。

手机基准为 390 × 844，8pt 间距体系，横向边距 20–24，触控目标至少 48，普通文字对比度目标 4.5:1。主题与文案使用语义化设计令牌，便于后续映射到 ArkUI resources。

## 页面与状态

首页突出连接状态、当前节点和连接／断开操作；连接成功后展示已验证的出口 IP。包含未连接、连接中、验证中、已连接、失败和没有节点等状态。

节点页展示地区、名称、协议与选中状态。没有节点时引导添加订阅；连接时更换节点需先断开。当前不设计尚未实现的测速、自动优选和流量统计。

订阅页提供地址输入、保存并刷新、清除确认，以及加载、成功、格式错误和下载失败反馈。

## 原型数据

所有展示数据均为虚构示例，出口 IP 使用文档地址 203.0.113.24，订阅占位地址使用 https://example.com/subscription。没有向 Figma 提供真实订阅链接、节点服务器、UUID、密钥或源码文件。

原型中的连接和下载仅用于演示，不执行真实网络代理操作。
