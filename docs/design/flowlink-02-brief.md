# FlowLink · 第二批核心功能

日期：2026-10-21。继续在 [FlowLink Design Review Workspace](https://www.figma.com/make/xh3PiB8zKAYfgvqgSsNVRe/) 中生成。

## 本批范围

沿用第一批设计系统，新增 P04 节点列表、P06 订阅管理、P07 添加订阅、P09 代理模式选择。第三批的详情和统计页面、第四批的设置页面不在本批展开。

- 节点：搜索、地区节点组和来源订阅筛选、排序、模拟批量测速、选中状态，以及空数据／无搜索结果／超时反馈。
- 订阅管理：模拟额度、到期、节点数、更新状态、失败重试、删除确认和未配置状态。
- 添加订阅：名称和地址表单、格式校验、模拟粘贴和文件导入、保存反馈和放弃草稿确认。
- 代理模式：规则／全局／直连，区分草稿选项和已应用模式，应用后同步首页。

## 原型流转

首页节点切换 → 节点列表 → 选择后回首页；首页模式行 → 模式选择 → 应用后回首页；订阅管理 → 添加订阅 → 校验及保存 → 返回更新后的列表。一级页保留四目的地导航，二级页只显示顶部返回。

活跃连接期间不能假装切换节点；订阅更新失败保留原有节点和上次成功数据；删除仅操作原型模拟数据并二次确认。

## 一致性和适配

保留已修正的主操作蓝色 #3268D6、英文侧栏和限定代理范围的说明。组件复用，浅深主题、中英文、大字体和 320/390/840/1024vp 预览共同适配。

总览缩略图应整体等比缩放，避免仅压缩画布宽度导致内容意外裁切。主操作与正文对比度目标至少 4.5:1，主要触控区域至少 48vp。使用中性系统安全区。

## 数据边界

所有订阅、节点、延迟、额度、时间及代理状态均为演示数据。订阅样例仅用 `https://example.com/subscription/demo`；粘贴和文件导入只注入预定义样例，不读取用户真实剪贴板或文件。禁止真实网络、VPN 或测速调用。本轮不修改本机 ArkTS 应用代码，不公开发布或修改文件分享权限。
